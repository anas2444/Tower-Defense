# Tower Defense

A 2D tower defense game developed in Unity using C#.

## Features
- Enemy wave spawning system
- Tower placement mechanics
- Enemy AI and path movement
- Shooting and damage system
- Tower upgrade system
- UI and game management system
- Different enemy types

## Tools Used
- Unity Engine
- C#
- Visual Studio

## Gameplay
This project was created as part of my Unity game development learning journey to improve gameplay programming, enemy AI, and game mechanics.
